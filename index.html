Privacy Policy – Photo Moderation Assistant

Last updated: October 2, 2026

Overview

Photo Moderation Assistant is an internal Chrome extension intended only for authorized employees performing photo moderation and photo verification. It operates exclusively on designated internal administration pages.

Data handled by the extension

To provide its moderation features, the extension may process the following information displayed by the internal administration system:

  • Internal profile ID, nickname, email address, age and gender.
  • Profile country and registration country at country level only.
  • The moderation decision selected by the moderator and its timestamp.
  • Interface content required for keyboard shortcuts, navigation and decision history.

The extension does not access precise GPS location, financial information, medical information, personal communications or passwords. It does not copy or store users' photo files.

Local storage

The extension uses chrome.storage.local to store interface settings, local counters and a short history of the last five processed profiles. This information is used only to help moderators navigate between recently processed profiles and correct an accidental decision.

Locally stored information remains in the moderator's browser and is not transmitted to the extension developer or to external third parties.

Internal system access

The extension may request profile country information from the same internal administration system at admin.ddkit.io. Such requests use the moderator's existing authorized session and remain within the same internal company system.

An existing session authorization value may be used temporarily in memory for this same-origin request. It is not written to extension storage and is never transmitted outside the internal administration system.

Data sharing and external services

The extension does not sell, transfer or disclose user data to advertisers, data brokers or other third parties. It does not use analytics, advertising services or external tracking services.

Data is not used for advertising, marketing, creditworthiness, lending or any purpose unrelated to internal photo moderation and fraud prevention.

Limited Use

The use of information by Photo Moderation Assistant complies with the Chrome Web Store User Data Policy, including the Limited Use requirements. Information is used only to provide the extension's disclosed moderation and verification functionality.

Data retention and removal

Only the last five processed profiles and temporary local statistics are retained by the extension. This local information can be removed by clearing the extension's storage or uninstalling the extension.

Changes to this policy

This policy may be updated if the extension's functionality or data handling practices change. The latest version will always be available on this page.
